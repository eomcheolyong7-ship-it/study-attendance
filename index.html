출결과 사진을 보관할 무료 저장소(Firebase)를 한 번만 연결하면 됩니다

설정 순서

  1. console.firebase.google.com 접속 → 프로젝트 추가 (이름은 자유, 애널리틱스는 꺼도 됩니다)
  2. 왼쪽 빌드 → Firestore Database → 데이터베이스 만들기 → 위치는 asia-northeast3 → 테스트 모드로 시작
  3. 왼쪽 빌드 → Authentication → 시작하기 → 익명 선택 → 사용 설정 후 저장
    이 사이트에 들어온 사람만 데이터를 읽고 쓰게 만드는 장치입니다. 스터디원이 따로 로그인할 일은 없습니다.
  4. Firestore Database → 규칙 탭에서 아래 내용으로 바꾸고 게시 
    rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{doc=**} {
      allow read, write: if request.auth != null;
    }
  }
}
  5. 프로젝트 개요 옆 톱니바퀴 → 프로젝트 설정 → 아래 내 앱에서 </>(웹) 선택 → 앱 등록 → 나오는 firebaseConfig 중괄호 안의 내용을 복사
  6. 복사한 값을 아래에 붙여넣으세요. index.html 파일의 맨 윗부분 FIREBASE_CONFIG에 같은 값을 넣어 두면 다른 사람들도 바로 쓸 수 있습니다.

firebaseConfig 붙여넣기

붙여넣은 값은 이 브라우저에만 저장됩니다. 스터디원 모두가 쓰려면 index.html 파일에 직접 넣은 뒤 다시 올려 주세요.
위 규칙은 링크를 아는 사람이면 데이터를 읽고 쓸 수 있는 상태입니다. 개인 비밀번호는 서로를 구분하는 간단한 장치이지 보안 장치가 아니니, 민감한 사진이나 정보는 올리지 마세요.
